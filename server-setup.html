Run your own AI at home

Use a model on your own computer with Reword. Your messages go from your phone to your computer and nowhere else.

This guide uses Ollama (free software that runs AI models on your computer) and Tailscale (a free service that gives your computer a secure https:// address your phone can reach, at home or away). Reword from Google Play only connects to servers over https://, so a plain address like http://192.168.1.20:11434 will not work.

Before you start
  • Your computer must be on and awake whenever you use Reword with it. If it sleeps, Reword cannot reach it.
  • You need a reasonably modern computer. 16 GB of memory is a good start, and a graphics card helps a lot. Without one, answers can take many seconds.
  • This uses other people's software (Ollama and Tailscale). Their steps and menus change from time to time; if something here does not match what you see, their own websites are the final word.

Step 1: Install Ollama

Windows 11

Open Windows Terminal (right-click Start, then Terminal) and paste:

winget install Ollama.Ollama

No winget? Download the installer from ollama.com/download/windows.

Linux

curl -fsSL https://ollama.com/install.sh | sh

Step 2: Download a model

Pick one that fits your computer. The download is large, so use a fast connection.

  • Modest computer (8 GB of memory, no graphics card): gemma4:e2b (about 4.6 GB)
  • Most computers (16 GB of memory or a mid-range graphics card): gemma4:e4b (about 6.6 GB)
  • Strong graphics card (12 GB of video memory or more): gemma4:12b (about 8 GB)

Paste this, using the name you picked (this one is the middle choice), in Terminal on Windows or in a Linux terminal:

ollama pull gemma4:e4b

Check that it answers:

ollama run gemma4:e4b "Say hello in five words"

Type /bye to leave.

Step 3: Let Tailscale reach Ollama

By default Ollama listens only to its own computer and refuses requests that arrive under another name, which is how Tailscale delivers them. So we tell Ollama to listen on all of the computer's network addresses.

Warning: after this step, anyone on your home network (and anyone you let onto your Wi-Fi) can use your Ollama. It has no password. That is usually fine at home. Never forward a port on your router to it and never put it on the internet.

Windows 11

In Terminal:

setx OLLAMA_HOST "0.0.0.0:11434"

Then right-click the Ollama icon near the clock (you may need the little arrow to see it), choose Quit Ollama, and start Ollama again from the Start menu. If Windows asks whether to allow Ollama through the firewall, allow it on Private networks only.

Linux

sudo mkdir -p /etc/systemd/system/ollama.service.d
printf '[Service]\nEnvironment="OLLAMA_HOST=0.0.0.0:11434"\n' | sudo tee /etc/systemd/system/ollama.service.d/reword.conf
sudo systemctl daemon-reload
sudo systemctl restart ollama

Step 4: Install Tailscale and give it an https address

  1. Make a free account at tailscale.com if you do not have one.
  2. Install Tailscale on your computer and sign in:

    Windows 11

    winget install Tailscale.Tailscale

    Then open Tailscale from the Start menu and sign in. Close and reopen Terminal afterwards.

    Linux

    curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

    Open the link it prints and sign in.

  3. Install the Tailscale app on your phone (Google Play), sign in with the same account and turn it on.
  4. Open login.tailscale.com/admin/dns, find HTTPS Certificates and click Enable HTTPS.
  5. On your computer, give Ollama its https address:

    Windows 11

    tailscale serve --bg 11434

    Linux

    sudo tailscale serve --bg 11434
    If it prints a link asking you to enable something, open it, approve, and run the command again.
  6. See your address:

    Windows 11

    tailscale serve status

    Linux

    sudo tailscale serve status
    It looks like https://my-computer.tail1234.ts.net. Copy it.

Check it from your phone: with Tailscale turned on, open that address in the phone's browser. It should say Ollama is running.

Note: the names of Tailscale devices can end up in public certificate records. Give your computer a name you do not mind being public.

Step 5: Connect Reword

  1. Open Reword and go to step 1, Which AI should do the rewriting?, and choose My own server.
  2. Paste your address (the https://...ts.net one) into Server address. Leave Server key empty.
  3. Open Advanced and choose your model from the model pull-down (the one you downloaded).
  4. Tap Test. When it says Connected, you are done.

Tailscale has to be turned on on the phone, also when you are at home.

If something goes wrong

  • "Forbidden" or 403: Ollama is still listening only to its own computer. Repeat Step 3 and restart Ollama.
  • Test cannot connect: check Tailscale is on in the phone app, the computer is awake, and the address matches tailscale serve status exactly.
  • The model is missing from the pull-down: run ollama list on the computer to see what is installed.
  • The first rewrite is slow: the computer is loading the model. Later ones are faster. Ollama unloads the model after a few idle minutes by default.
  • Too slow overall: choose a smaller model in Step 2.

Stopping it

To stop sharing with your phone: tailscale serve reset (on Linux, with sudo). To make Ollama listen only on its own computer again, undo Step 3.
